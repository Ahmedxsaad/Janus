#   .  transparent      k  outline #12233F     w  coat #F7F7F7
#   a  amber #F39F19    b  DataHub blue        d  deep blue      r  red
#
# Red is state, never decoration: no frame below uses r. The renderer paints the
# collar tag red when a finding is live, and only then.
#
# A character is one file of this shape. Add frames by name; the loader reads
# whatever is here and the state machine in argos.js maps states onto them.
# Every frame must be 16 rows of exactly 16 characters, which tests/test_argos.py
# checks, so a mistyped row fails the suite rather than the window.
