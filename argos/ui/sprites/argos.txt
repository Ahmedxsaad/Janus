# Argos, 24x24, side profile facing right.
#
# One character per pixel, indexing the palette in sprites.js:
#   .  transparent          k  outline #12233F      w  coat #F7F7F7
#   g  coat shade #D3D9E4   a  amber #F39F19        o  amber shade #C97C0C
#   b  DataHub blue         d  blue shade           r  red
#
# Red is state, never decoration. Only two frames use r, and both are the bark:
# the collar tag goes red the moment a finding is live, and nothing else in the
# character is allowed to.
#
# A character is one file of this shape: a `# name` line opens a frame, and
# every line after it is a row. Add frames by name; the state machine in
# argos.js maps states onto them. Every frame is 24 rows of exactly 24
# characters, which tests/test_argos.py checks, so a mistyped row fails the
# suite rather than the window.
#
# The far pair of legs is drawn in the shade colour and a pixel behind the near
# pair. That one trick is most of what makes a flat two-colour dog read as
# three-dimensional, and it is what makes the four-frame walk legible at this
# size.
