## Who Can Participate

- Above legal age of majority in country of residence (at least 18 or age of majority where they reside).
- All countries/territories, excluding standard exceptions (see `07-official-rules.md`).

## Core Requirement (do not miss)

Build a **working software application that uses DataHub** to solve **one** of four challenge categories (or combine them). The project **must** incorporate the open-source DataHub platform **together with at least one** of:

- **MCP Server**
- **Agent Context Kit**
- **DataHub Skills**
- **Analytics Agent**
