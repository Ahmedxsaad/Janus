# Janus documentation

The engineering explanation behind the product: everything that was built, how it
works, and why each choice was made.

**New to the project?** Read [01-overview.md](01-overview.md), then
[03-components.md](03-components.md) for the full inventory of what exists.
**Reading the code?** Start at [02-architecture.md](02-architecture.md).
**Judging it?** [03-components.md](03-components.md) is the map,
[08-evaluation.md](08-evaluation.md) is the evidence.

## Three places to look, and what each one holds

| Where | What it is |
|---|---|
| [README.md](../README.md) | The whole product in one page: the problem, the measured claim, a quickstart |
| [docs.ahmedxsaad.me](https://docs.ahmedxsaad.me) | The reference manual: install, every command, every flag, every configuration key |
| This directory | The engineering explanation: what was built, how it works, and why |

Each subject is explained in one place and linked from the others.
